# Manual Windows acceptance checklist — do not skip before daily use

1. Create a test PortableApps parent directory, e.g. `C:\PortableApps-Test`. Use a separate portable copy, not your existing OBS configuration.
2. Extract the `OBSStudioPortable` folder from ZIP to that parent. Verify exactly one root-level `OBSStudioPortable.exe` with official OBS icon and expected `App\OBSStudio\bin\64bit\obs64.exe`.
3. Start `OBSStudioPortable.exe`. Confirm that the full OBS interface opens, lists local capture sources, loads plugins and closes normally.
4. Create a new profile and scene collection, then exit. Confirm files under `Data\OBSConfig\obs-studio\basic\profiles` and `...\scenes`.
5. Test browser-source docks, an actual local recording and closing OBS. Confirm browser-source data stays in the OBS portable configuration. Recording files can stay in the user-selected directory; this is by design.
6. Look in `Data\TraceGuard` for extra OBS-owned runtime paths and empty directories; check `Data\launcher.log`. Existing installed-OBS `%APPDATA%\obs-studio` data should remain unchanged.
7. Create `Data\keep-existing-data.txt`, exit OBS, move the entire `OBSStudioPortable` folder to another drive/path, start again and verify both the scene and sentinel persist.
8. For PAF generated by the **official tool**, open PortableApps Platform → Apps → Install a New App → select PAF → target the **PortableApps parent**. Confirm the launcher is discoverable and starts OBS.
9. Close OBS. Install the same PAF over the existing directory and verify `Data\keep-existing-data.txt` and all user settings have unchanged contents.
10. Test a crash/restart scenario with throwaway profiles and backups, then check for recoverable `Data` files and any warnings in `launcher.log`. Do not manually delete a junction to recover settings.
11. For installed OBS plus portable OBS on the same machine, close the installed instance before starting the portable one. The launcher intentionally blocks potential concurrent access.
12. If using the virtual camera, independently check OS driver/filter registration. The portable builder does not install a virtual camera driver.

A PAF archive passing `7z t` is **not** equivalent to this installation/upgrade acceptance checklist.
